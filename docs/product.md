# 제품 방향

## 제품 개요

내일나이테는 사용자가 자신의 이력서와 관심 채용공고를 한곳에서 관리하고, 두 자료의 적합도를 근거 기반으로 비교하며, 공고별 지원 과정을 추적하는 한국어 웹 서비스다.

제품이 해결해야 하는 핵심 문제는 다음과 같다.

1. 여러 이력서 버전과 실제 제출본을 잃어버리지 않게 관리한다.
2. 관심 채용공고의 내용과 마감일을 보존한다.
3. 이력서와 공고 사이의 일치점과 부족한 점을 근거와 함께 보여준다.
4. 공고에 맞춘 이력서를 만들되 사용자가 모든 변경을 검토하고 승인하게 한다.
5. 관심부터 합격 또는 불합격까지 지원 상태와 다음 행동을 관리한다.

## MVP 우선순위

1. 이력서 등록, 조회, 수정 및 버전 관리
2. 채용공고 저장, 조회, 수정, 원문 보존 및 마감일 관리
3. 이력서와 채용공고의 근거 기반 매칭 분석
4. 공고별 맞춤 이력서 제안과 변경 승인
5. 지원 현황 칸반과 다음 행동 관리
6. 공고별 실제 제출 이력서 스냅샷 보관

후속 기능 때문에 MVP 구조를 과도하게 일반화하거나 복잡하게 만들지 않는다.

## 핵심 사용자 흐름

```text
이력서 등록
→ 채용공고 저장
→ 이력서와 공고 비교
→ 일치 근거와 부족한 정보 검토
→ 공고별 이력서 제안 검토 및 승인
→ 지원 및 제출본 저장
→ 전형 상태와 다음 행동 관리
```

## 후속 기능

- 공고 비교와 공통 요구사항 분석
- 마감 및 면접 일정 알림
- 면접 질문, 답변, 과제, 처우 및 회고 기록
- 지원 통계와 자주 요구되는 역량 분석
- 브라우저 확장 프로그램을 통한 공고 저장
- 캘린더 및 이메일 연동
- 모의 면접과 포트폴리오 추천

## UX 원칙

- 제품 언어는 한국어를 기본으로 한다.
- 전문적이되 딱딱하지 않고, 단순하며 살짝 따뜻한 인상을 지향한다.
- 나무와 나이테는 성장과 축적을 표현하는 보조 메타포로만 사용한다.
- 핵심 행동은 `이력서 등록하기`, `채용공고 저장하기`, `비교하기`, `지원 준비하기`처럼 명확하게 표현한다.
- 빈 상태에서는 사용자가 취할 다음 행동을 안내한다.
- AI 결과와 사용자가 직접 입력한 내용을 시각적으로 구분한다.
- 분석 결과는 점수보다 근거와 다음 행동을 먼저 보여준다.
- 오류가 발생해도 사용자의 원문과 편집 중인 내용을 잃지 않게 한다.
- 색상만으로 상태를 구분하지 않고 키보드와 보조기술 접근성을 고려한다.
- 모바일에서도 공고 저장, 상태 확인 및 메모가 가능해야 한다.
